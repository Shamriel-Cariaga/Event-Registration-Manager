Event Registration Management

The Event Registration Management is a java-based application developed to manage events and participant registrations. 
It allows users to create events, register participants, update information, search records, and manage registrations 
through a simple graphical user interface.

Technology Used
* Java
* Apache NetBeans IDE
* Arrays
* Linear Search
* Text File Handling

Features

1. Dashboard
* Display the total number of events.
* Display the total number of registered participants.
* Shows Upcoming Events
* Provides navigation to other forms.

2. Event Management
* Add new events.
* Update event information.
* Delete events.
* Display event records in a table.

3. Participant Registration
* Register new participants.
* Select event from the available events.
* Update participant information.
* Delete registrations.
* Search participants using Registration ID or Participant Name.
* Display registered participants in a table.

How to use
1. Open the Dashboard.
2. Go to Event Management and create an event.
3. Open Participant Registration.
4. Enter the participant's information.
5. Select an available event.
6. Click Register to save the participant.
7. Use the Search, Update, and Delete buttons to manage registration records.

Data Structures and Algorithms Used

* Array
Arrays are used to store event information and participant registration records.

* Linear Search
Linear Search is used to find event records through Event ID and participant records through Registration ID or Participant Name.
